# 🎯 Placement Prep Tracker

A simple web application to help track my placement preparation and DSA practice.

This project is being built from scratch as a learning project while improving my **HTML, CSS, JavaScript, and Git/GitHub** skills.

## 🚀 Features

* Track DSA questions
* Organize questions by topic
* Mark questions as completed
* Track placement preparation progress
* Simple and beginner-friendly interface

> 🚧 This project is currently under development.

* JavaScript
* Git
